Short Introduction

CASIO fx-50FHII（会考准用计算器）是一款可编程计算器（Programmable calculator），具备完整的编程功能，程序空间大小为 680B 。除了无条件转移指令外，还支持结构控制指令（Control structure command），能够编写出较为复杂的程序。

我在这里整理了一些程序，主要是香港文凭试常用且实用的类型，希望能帮助自己和各位同学应付考试。需要说明的是，这些程序与网上零散分布的独立 Programs 不同——我将直接提供完整的 Programs Set，力求在有限的 680B 编程空间内容纳更多功能。我相信这样的 Programs Set 实用性会大大提高，而不是像零散的 Programs 那样，大家在照抄其他网站的程序时可能也深有感触：经常因为空间不足而浪费不少步数，到了考试时因缺乏程序的辅助，答题速度比别人慢了不少；面对不确定的答案又无法正确验算，那时再后悔就来不及了。

此外，本文也会一并讨论 CASIO fx-50FHII 的编程使用技巧。如果你有信心创建属于自己的程序，这部分内容将为你提供最大的帮助。

Appendix

程式特別指令或符號的按法

  • 什么是Key Markings?
    • 计算机上每一个按钮在不同计算模式或者 SHIFT 或者 ALPHA 状态下输入的内容各有不同

IndexExample FunctionsColors如何输入？
(1)M+直接按下对应按钮
(2)M-Amber先按SHIFT再按下对应按钮
(3)MRed先按ALPHA再按下对应按钮
(4)DTBlue在SD或者REG模式下直接按下对应按钮
(5)CLAmber [Blue]在SD或者REG模式下 先按SHIFT再按下对应按钮
(6)∠Amber [Purple]在COMPLX模式下直接按下对应按钮
(7)ARed先按ALPHA再按下对应按钮
(7)A(HEX: 10)Green在BASE模式下直接按下对应按钮
(8)LOGICGreen在BASE模式下直接按下对应按钮
  • 如何进入各种模式？
    • 我们通过 MODE Number 1-6 进入不同模式 有一些模式需要按多个数字进入不同子模式
    • MODE 1 进入 COMP 模式
    • MODE 2 进入 CMPLX 模式
    • MODE 3 进入 BASE 模式
    • MODE 4 进入 SD 模式
    • MODE 5 进入 REG 模式
      • 紧接着按数字1~4或者可以选择←→REPLAY选择按钮可以进入不同子模式
      • 再按1进入REG Lin 模式 (Linear Regression)
      • 再按2进入REG Log 模式 ( Exponential Regression)
      • 再按3进入REG Exp 模式 (Linear Regression)
      • 再按4进入REG Pwr 模式 (Power Regression)
      • 再按→1进入REG Inv 模式 (Inverse Regression)
      • 再按→2进入REG Quad 模式 (Quadratic Regression)
      • 再按→3进入REG AB-Exp 模式 ( Exponential Regression)
    • MODE 6 进入 PRGM 模式
      • 紧接着按数字1~4按钮可以进入不同子模式；或者你可以在进入该模式页面之后按下EXE, AC或者DEL来改变其子模式 这部分内容请参考下一章的内容

Programs页面的使用

这部分内容参考了CASIO Fx-50FH II的官方说明书 我会尽量把其中的内容解释的通俗易懂

Program页面

  1. 按MODE 6进入Program Mode的模式选择页面。
  2. 你可以按1进入编辑模式；按2进入运行模式；按3进入删除模式。详细内容会在接下来的部分讨论到，现在我们可以随便按一个数字进入Program Mode的主页面。
  • 正上方显示P1, P2, P3或者P4的数字就代表该Program栏位已经填入代码。
  • 右侧显示的三位数字就是你剩余Program字节的数量

计算机自我检测功能

在计算过程中出现错误，或计算结果与预期不符时，请按以下步骤操作，逐步检查，每个步骤对计算机内部运算逻辑的检查将会更加深入。若某一步骤未能解决问题，请继续执行下一步。请注意，在执行这些步骤前，务必备份重要数据。

  1. 检查计算表达式，确保其中不存在任何错误。
  2. 确认当前所使用的模式与您要执行的计算类型相匹配。

Warning: 从当前步骤开始计算机将会清除所有用户配置包括但不限于SETUP中的配置以及所有Programs代码

  1. 如果上述步骤未能恢复正常运行，请ON按键。计算器将在启动时进行状态自检。若计算器发现问题，其计算模式及设置将恢复为初始默认值，且当前内存中的所有数据将被清除。
  2. 运行计算机的自我检测功能
  3. 如果步骤 [4] 未能恢复正常运行，请依次按SHIFT 9 3初始化所有模式及设置。显示DATA CLEAR!

警告: 执行计算器的自我检测功能(self-test function)会引致记忆中的数据及程序被清除。

执行计算机中的自我检测方法如下:

  1. 先同时按下SHIFT 7 ON， 这时计算器第一行会显示DIAGNOSTIC，第二行则显示AC。
  2. 在DIAGNOSTIC及AC未自动消失前，再按9进入显示测试，这时计算器会显示所有内容，再按 SHIFT 会出现完全空白的显示，再按 SHIFT SHIFT 有二个不同的图样会被显示，确保你目视检查清楚计算机所有显示像素都可以被正常显示控制
  3. 再按 SHIFT 计算器的显示测试会完成，这时会第一行会显示 GY-347 VerA P-，第二行显示AC。这个显示表示计算器的主板硬件版本为GY-347 VerA，且当前处于特定P模式（自检）的状态。
  4. 再按 AC 等候计算器显示 SUM-DF51-OK R-OK。这组显示表明计算器的核心硬件（如 ROM）和内部存储数据通过了完整性检查，功能正常。
  5. 再按 AC 进入对比度测试，对比度数值由一个二位十六进数表示，按向左键 ← 数值会减1，屏幕字体会变暗一点，按向右键 → 数值会加1，屏幕字体变亮一点，而对比度的测试范围00至1F。
  6. 再按 AC 离开对比度测试及进入键盘测试，这时会显示00，首先的十一个按键的次序较特别，按 SHIFTALPHA↑→MODEProgFMLA←↓ <!--mathjax:74:inline:sp--> <!--mathjax:75:inline:sp--> 接着是按第三行的a b/c按键，每一行的次序是由左向右按，按完一行后再按下一行，直至所有按键都被按下，键盘测试亦完成，这时第一行会显示TEST OK及第二行显示AC，这时可以按任何键离开。

　

  • 当计算器显示DIAGNOSTIC及AC时，若果不想进行自我检测，可以直接按AC离开，或等数秒亦会自动离开，这时计算器内的数据、程序及设定不会被删除。
  • 当按下 9 进入显示测试，计算器的自我检测正式进行，这时无论是按 ON 中途终止测试或完成整个测试，计算器内的数据、程序及设定(对比度除外(注3))都会被删除。
  • 对比度的测试范围为00至1F，但计算器正常显示使用对比度数值为00至14，15至1F数值只供自我测试使用，若选用这个范围数值，当下一次按 ON 时，计算器会自动执行重设功能，回复至默认值13。
  • 当显示TEST OK及AC时，若果按 ON 离开，计算器的对比度数值会自动回复至默认值13，若按其它键离开，对比度的数值则会被保留，不过若果对比度数值为15至1F，在下一次按 ON 时，计算器会自动执行重设功能，回复至默认值13。
